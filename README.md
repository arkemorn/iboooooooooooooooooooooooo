# УВМ: вариант 18

Проект реализует ассемблер и интерпретатор учебной виртуальной машины.
Ассемблер читает CSV-подобный исходный файл, формирует 11-байтовые команды,
а интерпретатор исполняет их с раздельной памятью команд и данных.

## Требования

- Python 3.10 или новее.
- Внешние библиотеки не требуются.

## Запуск

```text
python run.py assemble examples/and.csv program.bin --test
python run.py interpret program.bin memory.xml 0 32
python run.py interpret copy.bin copy-dump.xml 0 202 --input examples/input.xml
python -m unittest discover -s tests -v
```

Команда `assemble` принимает исходник, путь бинарного результата и
необязательный флаг `--test`. В режиме проверки печатаются поля каждой
команды и байты результата. В обычном режиме печатается размер файла.

Команда `interpret` принимает бинарный файл, имя XML-дампа памяти,
начальный и конечный адрес включительно. Дамп создаётся после исполнения.

## Формат исходного кода

Каждая строка содержит код операции и операнды через запятую. Пустые строки
и строки, начинающиеся с `#`, игнорируются. Допускаются десятичные и
шестнадцатеричные числа (`0x...`). Поля должны помещаться в разрядность,
заданную командой.

| Код | Команда | Поля и действие |
| --- | --- | --- |
| 2 | `LOAD` | `A, B, C`: память[`B`] = `C` |
| 7 | `READ` | `A, B, C, D`: память[`D`] = память[память[`C`] + `B`] |
| 6 | `WRITE` | `A, B, C, D`: память[память[`C`] + `D`] = память[`B`] |
| 3 | `AND` | `A, B, C, D`: память[память[`C`]] = память[`D`] & память[`B`] |

В одном тестовом байтовом примере для `WRITE` напечатано `0x83`, хотя
указанный код операции 6 и поле B=816 дают `0x86` в первом байте.
Программа следует битовой раскладке и указанному коду операции.

В таблице A обозначает код операции. Поля записываются младшим битом вперёд,
в порядке таблицы. Каждая команда занимает 11 байт; неиспользуемые старшие
биты последнего байта равны нулю. Адреса памяти данных — 28-битные
беззнаковые числа. Значения памяти и константы — 32-битные беззнаковые числа.

## Примеры и тесты

`examples/specification.csv` содержит команды из тестовых примеров спецификации.
`examples/copy.csv` копирует три слова между областями памяти, а
`examples/and.csv`, `examples/and-high-bits.csv` и `examples/and-sparse.csv`
выполняют AND над тремя векторами и разными масками. Исходные данные лежат
в соответствующих XML-файлах в `examples/`.

Тесты проверяют байты из спецификации, кодирование, ошибки формата,
запись и чтение памяти, а также выполнение программ.
